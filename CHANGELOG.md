# HomeGuest Changelog

## 0.2.0-beta.1

Первая публичная beta-версия HomeGuest.

### Основные возможности

- первоначальная настройка через web-мастер;
- настройка пароля администратора;
- проверка и сохранение Yandex token;
- интеграция с Yandex Smart Home;
- гостевые инструкции;
- управление доступными гостям устройствами;
- отображение состояния устройств;
- температура и влажность;
- QR-код гостевой страницы;
- Backup / Restore;
- системная диагностика;
- health и readiness проверки;
- проверка состояния базы данных;
- защита от нескольких одновременно запущенных экземпляров;
- Keenetic supervisor и автоматический перезапуск;
- встроенная проверка update package;
- автоматический backup перед обновлением;
- обновление HomeGuest;
- rollback предыдущей версии.

### Протестировано

Beta.1 прошла:

- локальные Go tests;
- `go vet`;
- сборку MIPSLE softfloat;
- установку на реальный Keenetic;
- первоначальную настройку с чистого состояния;
- подключение Yandex Smart Home;
- загрузку устройств;
- single-instance protection;
- автоматический перезапуск;
- update;
- rollback.

### Статус

Beta — предназначена для тестирования, а не для критичных production-систем.

# HomeGuest Changelog

## 0.4.0

Релиз HomeGuest с голосовыми сообщениями через Яндекс Станции.

### Новое

- голосовое сообщение гостя через Яндекс Станцию;
- выбор разрешённой колонки на гостевой странице;
- административная колонка по умолчанию;
- подключение и тест речи в админ-панели;
- текстовое объявление владельца дома для гостей;
- сохранение локальной сессии Яндекс между перезапусками.

### Безопасность и ограничения

- максимум 100 символов;
- принимается только обычный текст;
- rate limit гостевых сообщений;
- текст сообщения не пишется в audit log;
- список колонок фильтруется по существующему ACL HomeGuest;
- для колонки обязательны одновременно guest visibility и guest control;
- сервер повторно проверяет `station_id` при отправке.

### Проверено

- `go test ./...`;
- Windows amd64, Linux amd64, Linux arm64 и Keenetic MIPSLE softfloat builds;
- обновление на реальном Keenetic;
- выбор и TTS на разных Яндекс Станциях;
- сохранение default-колонки администратора;
- фильтрация колонок по ACL;
- запрет отправки на недоступную гостю колонку.

## 0.3.0

Релиз HomeGuest с поддержкой локальных сценариев для гостей.

### Новое

- локальные HomeGuest-сценарии;
- несколько действий в одном сценарии;
- действия `on_off` и `brightness`;
- отдельная страница администрирования сценариев;
- сценарии на гостевой странице;
- имя, описание, видимость и порядок сценариев;
- хранение сценариев в SQLite;
- включение сценариев в Backup / Restore;
- схема БД обновлена до версии 6.

### Безопасность и надёжность

- весь сценарий проходит preflight-проверку до первого действия;
- сценарий не может обойти guest visibility / guest control;
- устранена гонка refresh/action, которая могла возвращать устаревшее состояние;
- при отсутствии доступных устройств редактор явно сообщает об этом;
- сохранение некорректного сценария блокируется.

### Проверено

- `go test ./...`;
- Windows amd64 build;
- Keenetic Linux MIPSLE softfloat build;
- smoke-test на mock provider;
- сценарий «Включить + Яркость 35%»;
- запрет guest control;
- atomic preflight при недоступном последующем действии;
- обновление 0.2.0-beta.2 → 0.3.0 на реальном Keenetic;
- автоматический backup, restart и доступность rollback.

- выровненные элементы верхней панели администрирования.

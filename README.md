# HomeGuest

**HomeGuest** — локальное веб-приложение для домашней сети, которое помогает сделать умный дом удобным для гостей.

HomeGuest позволяет создать гостевую страницу с инструкциями по дому и предоставить безопасный доступ к выбранным устройствам умного дома.

## Возможности

- гостевая веб-страница, работающая внутри домашней сети;
- инструкции по помещениям и оборудованию;
- изображения и ссылки в инструкциях;
- правила дома;
- интеграция с Yandex Smart Home;
- отображение состояния устройств;
- температура и влажность с датчиков;
- управление разрешёнными гостевыми устройствами;
- отдельные названия и комментарии для гостей;
- QR-код гостевой страницы;
- мастер первоначальной настройки;
- резервное копирование и восстановление;
- диагностика состояния HomeGuest;
- автоматический перезапуск сервиса;
- защита от запуска нескольких экземпляров;
- встроенный механизм обновления и отката.

## Важно

HomeGuest находится в стадии beta-тестирования.

Перед обновлением или установкой новой версии рекомендуется сделать резервную копию.

Никогда не публикуйте в GitHub Issues:

- Yandex OAuth token;
- пароль администратора HomeGuest;
- содержимое каталога `data/secrets`;
- другие пароли, ключи и персональные данные.

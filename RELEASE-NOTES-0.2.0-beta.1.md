# HomeGuest 0.2.0-beta.1

Первая публичная beta-версия HomeGuest для Keenetic.

HomeGuest — локальное веб-приложение для домашней сети, которое позволяет создать удобную гостевую страницу с инструкциями по дому и предоставить гостям безопасный доступ к выбранным устройствам умного дома.

## Что доступно в beta.1

- мастер первоначальной настройки;
- создание пароля администратора;
- настройка и проверка Yandex Smart Home token;
- интеграция с Yandex Smart Home;
- гостевые инструкции с изображениями и ссылками;
- комнаты и правила дома;
- выбор устройств, доступных гостям;
- гостевые названия и комментарии устройств;
- отображение текущего состояния устройств;
- отображение температуры и влажности;
- QR-код гостевой страницы;
- Backup / Restore;
- системная диагностика;
- health и readiness проверки;
- проверка состояния базы данных;
- защита от запуска нескольких экземпляров HomeGuest;
- автоматический перезапуск сервиса;
- механизм обновления;
- автоматический backup перед обновлением;
- rollback предыдущей версии.

## Поддерживаемая платформа

На данном этапе публично тестируется:

**Keenetic / Entware / OPKG / Linux MIPSLE softfloat**

Поддержка других платформ будет добавляться позже.

## Сообщить об ошибке

Используйте раздел **Issues** этого репозитория.

При создании Issue желательно указать:

- модель Keenetic;
- версию KeeneticOS;
- версию HomeGuest;
- шаги воспроизведения;
- ожидаемый результат;
- фактический результат;
- обезличенный фрагмент лога, если он необходим.

### Безопасность

Никогда не публикуйте:

- Yandex OAuth token;
- пароль администратора HomeGuest;
- содержимое `data/secrets`;
- другие пароли, ключи и персональные данные.

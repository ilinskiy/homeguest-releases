# HomeGuest 0.2.0-beta.2

Вторая публичная beta-версия HomeGuest для Keenetic.

Главное изменение beta.2 — HomeGuest больше не ограничен только комнатами и устройствами, полученными от Yandex Smart Home. Владелец может создавать собственные комнаты и информационные устройства прямо в HomeGuest и прикреплять к ним полноценные гостевые инструкции.

## Что нового в beta.2

### Произвольные комнаты HomeGuest

Теперь можно создать комнату, которой нет в Yandex Smart Home, например:

- Баня;
- Терраса;
- Гараж;
- Гостевой дом;
- Кладовая.

Комнаты Yandex и комнаты HomeGuest отображаются вместе и доступны при настройке гостевого интерфейса.

### Произвольные устройства

Можно создать обычное устройство HomeGuest, не связанное с Yandex или другим провайдером.

Для такого устройства доступны:

- название;
- комната;
- гостевое имя;
- комментарий;
- видимость для гостей;
- сортировка;
- полноценная инструкция с текстом, ссылками и изображениями.

Ручное устройство является информационным: элементы управления Yandex для него не показываются.

### Инструкции для ручных устройств

Ручные устройства используют тот же редактор инструкций, что и остальные устройства HomeGuest:

- текст;
- ссылки;
- изображения;
- размер изображения 25 / 50 / 75 / 100%;
- удаление изображения;
- включение и выключение показа инструкции гостям.

При удалении ручного устройства связанная инструкция также удаляется.

### Административный интерфейс

Добавлены действия:

- **Добавить устройство**;
- **Добавить комнату**.

Также выровнена высота элементов верхней панели администрирования.

Beta.2 прошла:

- `go vet ./...`;

После распаковки начните с:

`README-FIRST.md`

Затем используйте:

`INSTALL-KEENETIC.md`

Для проверки beta используйте:

`TEST-CHECKLIST.md`

## Безопасность

Никогда не публикуйте:

- Yandex OAuth token;
- пароль администратора HomeGuest;
- содержимое `data/secrets`;
- cookie и другие данные авторизации;
- рабочую SQLite-базу или backup без предварительной очистки.

HomeGuest предназначен прежде всего для локальной домашней сети. Не публикуйте административную панель напрямую в Internet.

## Статус

Это beta-версия для тестирования. Перед установкой новой версии или экспериментами с обновлением рекомендуется создать Backup.

# HomeGuest 0.3.0 — Devices & Scenes

HomeGuest 0.3.0 adds local guest scenarios and strengthens device-action consistency and safety.

## Главное в 0.3.0

- локальные HomeGuest-сценарии;
- несколько действий в одном сценарии;
- поддержка `on_off` и `brightness`;
- отдельная страница управления сценариями: `/admin/scenes.html`;
- отдельный блок сценариев на гостевой странице;
- имя, описание, видимость и порядок сортировки сценариев;
- хранение сценариев в SQLite;
- включение сценариев в Backup / Restore;
- схема базы данных обновлена до версии 6.

## Безопасность сценариев

Перед запуском HomeGuest проверяет весь сценарий целиком:

- устройство должно оставаться доступным гостю;
- для устройства должно быть разрешено гостевое управление;
- устройство должно присутствовать в текущем registry/cache;
- устройство должно поддерживать требуемую capability.

Если проверка не проходит хотя бы для одного действия, ни одно действие сценария не выполняется.

После успешного preflight действия отправляются провайдеру последовательно. Если провайдер вернёт runtime-ошибку уже во время выполнения, последующие действия не запускаются, но ранее выполненные действия автоматически не откатываются.

## Исправления и hardening

- устранена гонка между refresh состояния и выполнением action, из-за которой старое состояние могло перезаписать результат сценария;
- после сценария состояние Вкл/Выкл и яркость остаются согласованными;
- при отсутствии устройств с гостевым управлением редактор показывает понятное сообщение вместо пустого списка;
- сохранение некорректного сценария блокируется.

## Безопасность

Никогда не публикуйте:

- Yandex OAuth token;
- пароль администратора HomeGuest;
- содержимое `data/secrets`;
- cookies;
- рабочую SQLite-базу;
- необезличенные backup-файлы.

HomeGuest предназначен прежде всего для локальной домашней сети. Не публикуйте административную панель напрямую в Internet.

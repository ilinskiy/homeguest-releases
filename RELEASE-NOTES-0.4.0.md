# HomeGuest 0.4.0 — Guest Voice Messages

HomeGuest 0.4.0 добавляет голосовые сообщения для гостей через Яндекс Станции и текстовые объявления владельца дома.

## Главное в 0.4.0

- гость может ввести короткое сообщение на главной странице HomeGuest и попросить Алису произнести его;
- гость выбирает конкретную доступную Яндекс Станцию перед отправкой;
- в список попадают только колонки, для которых одновременно разрешены «Показывать гостям» и «Разрешить управление»;
- проверка прав выполняется на сервере повторно при отправке, поэтому ID запрещённой колонки нельзя подставить вручную;
- колонка, выбранная администратором, используется как вариант по умолчанию;
- выбор гостя не меняет административную настройку;
- добавлено подключение Яндекс Станций через локальную сессию HomeGuest;
- администратор может выбрать колонку по умолчанию и выполнить тест речи;
- авторизация и выбранная колонка сохраняются между перезапусками;
- максимальная длина голосового сообщения — 100 символов;
- принимается только обычный текст;
- действует rate limit для защиты от частой повторной отправки;
- текст сообщения не записывается в audit log;
- добавлено текстовое объявление владельца дома для гостевой страницы.

## Совместимость

Обновление рассчитано на HomeGuest 0.3.0.

Сохраняются:

- устройства и комнаты;
- гостевые названия и комментарии;
- инструкции и изображения;
- правила дома;
- локальные сценарии;
- Provider Settings;
- настройки гостевой видимости и управления;
- существующая SQLite-база.

Новая версия схемы БД для 0.4.0 не требуется.

## Яндекс Станции

Голосовые сообщения используют интеграцию с сервисами Яндекс Станции через Quasar. Это не публичный Yandex Smart Home API, поэтому при изменениях со стороны Яндекса интеграция может потребовать обновления HomeGuest или повторной авторизации.

Для TTS HomeGuest должен иметь доступ в интернет к сервисам Яндекса.

Сессия Яндекса хранится только локально в HomeGuest и не включается в release-пакеты, backup для публикации или Git.

## Безопасность доступа

HomeGuest использует существующий ACL устройств.

Колонка доступна гостю для голосового сообщения только когда для соответствующего устройства Yandex одновременно включены:

- «Показывать гостям»;
- «Разрешить управление».

Фильтрация действует как при выдаче списка колонок, так и непосредственно перед выполнением TTS-команды.

## Безопасность

Никогда не публикуйте:

- Yandex OAuth token;
- пароль администратора HomeGuest;
- содержимое `data/secrets`;
- cookies и данные сессии Яндекса;
- рабочую SQLite-базу;
- необезличенные backup-файлы.

HomeGuest предназначен прежде всего для локальной домашней сети. Не публикуйте административную панель напрямую в Internet.

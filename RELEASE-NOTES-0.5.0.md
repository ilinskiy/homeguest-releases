# HomeGuest 0.5.0 — Guest Access and Information

HomeGuest 0.5.0 расширяет гостевой режим: временный доступ, гостевой Wi-Fi, полезная информация, запросы хозяину и улучшенная работа с Яндекс Станциями.

## Главное в 0.5.0

- глобальный гостевой доступ можно включать, отключать и ограничивать по времени;
- HomeGuest может показывать гостю существующую Wi-Fi сеть и QR-код для подключения;
- добавлены карточки «Полезная информация» с текстом, ссылками и сортировкой;
- добавлена функция «Запрос хозяину» с категориями, комментариями и статусами;
- «Запрос хозяину» можно полностью отключить в админке;
- список Яндекс Станций можно обновлять без повторной авторизации;
- гостевой TTS использует ACL HomeGuest и показывает точный cooldown при rate limit;
- административная диагностика показывает результат последней TTS-отправки без хранения текста сообщения.

## Временный гостевой доступ

Владелец может:

- полностью открыть или закрыть гостевой доступ;
- задать дату и время автоматического окончания доступа;
- оставить доступ бессрочным.

После закрытия или истечения срока сервер блокирует гостевые API, а административная панель продолжает работать.

## Wi-Fi для гостей

HomeGuest не меняет настройки Keenetic. В админке задаются данные уже существующей Wi-Fi сети.

Поддерживаются:

- SSID;
- пароль;
- Wi-Fi QR-код;
- отдельная настройка показа пароля текстом.

Пароль Wi-Fi хранится локально в `data/secrets/guest_wifi.json` с ограниченными правами и не включается в обычный backup HomeGuest или release-пакеты.

## Полезная информация

Владелец может создавать карточки для гостя:

- информация;
- парковка;
- мусор;
- баня/сауна;
- выезд;
- контакт;
- адрес;
- экстренная информация.

Карточки можно скрывать, сортировать и снабжать ссылками `http`, `https`, `tel` и `mailto`.

## Запрос хозяину

Гость может отправить короткий запрос прямо из HomeGuest.

Категории:

- нужна помощь;
- проблема с Wi-Fi;
- не работает устройство;
- вопрос по дому;
- другое.

Комментарий необязателен, максимум 500 символов.

В админке доступны статусы:

- Новый;
- Просмотрен;
- Решён.

Функция является опциональной и по умолчанию может оставаться выключенной. При отключении форма исчезает с гостевой страницы, сервер запрещает новые запросы, а ранее созданные запросы сохраняются.

Действует rate limit: один запрос с одного IP не чаще чем раз в 30 секунд и глобально не чаще одного запроса за 2 секунды.

Текст запроса не записывается в audit log.

## Яндекс Станции и голосовые сообщения

- список станций обновляется без повторной авторизации;
- выбранная станция сохраняется, если она всё ещё доступна;
- гостю выдаются только станции, разрешённые существующим ACL HomeGuest;
- успешная отправка показывает конкретную колонку;
- при rate limit показывается точный обратный отсчёт;
- административная диагностика хранит только технический результат последней TTS-операции, без текста сообщения.

## Совместимость и база данных

Обновление рассчитано на HomeGuest 0.4.0.

Существующие настройки, устройства, комнаты, инструкции, сценарии и гостевые ACL сохраняются.

Схема SQLite обновляется до версии 7. Новая таблица `guest_requests` включена в Backup / Restore.

Настройки временного гостевого доступа, информационные карточки и флаг функции запросов хранятся в существующей таблице `settings`.

## Безопасность

Никогда не публикуйте:

- Yandex OAuth token;
- пароль администратора HomeGuest;
- содержимое `data/secrets`;
- cookies и данные сессии Яндекса;
- рабочую SQLite-базу;
- необезличенные backup-файлы.

HomeGuest предназначен прежде всего для локальной домашней сети. Не публикуйте административную панель напрямую в Internet.

# HomeGuest 0.6.0 — Personal Guest Invitations

HomeGuest 0.6.0 добавляет персональные приглашения для конкретных гостей и заездов без создания аккаунтов и паролей.

## Главное в 0.6.0

- отдельная административная страница «Гости»;
- персональная ссылка вида `/g/<token>` и QR-код;
- имя гостя или название заезда;
- дата и время начала и окончания доступа;
- статусы «Будущее», «Активно», «Завершено», «Отозвано»;
- мгновенный отзыв приглашения;
- перевыпуск персональной ссылки;
- отдельные разрешения на Wi-Fi, полезную информацию, голосовые сообщения и «Запрос хозяину»;
- отдельный список устройств и сценариев для каждого приглашения;
- режим «Требовать персональное приглашение»;
- существующий общий гостевой режим 0.5.0 сохранён для обратной совместимости.

## Безопасность

Персональное приглашение только сужает уже существующие гостевые ACL HomeGuest.

- устройство должно быть разрешено обычному гостевому ACL и отдельно выбрано в приглашении;
- сценарий должен быть включён для гостей и отдельно выбран в приглашении;
- ограничения повторно проверяются сервером;
- токен создаётся из криптографически случайных данных;
- в SQLite хранится только SHA-256 hash токена;
- исходный токен не возвращается при обычном чтении списка приглашений;
- перевыпуск токена инвалидирует предыдущую ссылку;
- токен не записывается в audit log;
- путь `/g/<token>` маскируется в HTTP-журнале как `/g/[redacted]`;
- гостевые audit-события по персональной ссылке получают `invitation_id`.

## Режим «только по приглашениям»

В настройках гостевого доступа можно включить требование персонального приглашения.

При включении:

- обычная гостевая ссылка не даёт доступ к содержимому дома;
- работают только активные персональные приглашения;
- глобальный переключатель «Гостевой доступ» остаётся master switch и может закрыть весь гостевой доступ сразу.

По умолчанию этот режим выключен, чтобы обновление с 0.5.0 не меняло текущий сценарий работы.

## База данных и Backup / Restore

Схема SQLite обновлена до версии 8.

Добавлены таблицы:

- `guest_invitations`;
- `guest_invitation_devices`;
- `guest_invitation_scenes`.

Приглашения, сроки, права, ACL устройств и сценариев включены в обычный Backup / Restore.

## Безопасность публикации

Не публикуйте:

- Yandex OAuth token;
- пароль администратора HomeGuest;
- содержимое `data/secrets`;
- cookies и данные сессии Яндекса;
- рабочую SQLite-базу;
- необезличенные backup-файлы.

HomeGuest предназначен прежде всего для локальной домашней сети. Не публикуйте административную панель напрямую в Internet.

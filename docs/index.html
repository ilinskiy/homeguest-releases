FAQ

Коротко о главном

HomeGuest работает через интернет?

Основной интерфейс HomeGuest предназначен для работы внутри домашней сети. Для интеграции с Yandex Smart Home используется подключение к провайдеру.

Гость увидит все мои устройства?

Нет. Доступ задаётся владельцем отдельно. Подход HomeGuest — deny by default: устройство не показывается гостю, пока вы его явно не разрешили.

Где хранится Yandex token?

Токен хранится локально HomeGuest и не показывается обратно через интерфейс или API.

Это уже стабильная версия?

Нет. 0.2.0-beta.1 — публичная beta для тестирования. Перед экспериментами с обновлениями рекомендуется делать резервную копию.
